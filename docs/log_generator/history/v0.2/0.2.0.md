## [v0.2.0] - 2026-06-18

### 新增功能 (Added)
* 新增区间事件生成支持 `EventStyle::Interval`（在 `EventGenerator::build_interval_events` 中实现）。**此项改动是为了配合 libs 端新增支持区间记录事件（如 `HHMM-HHMM activity` 语法格式）解析与校验的新能力**：以前生成器仅支持生成单点时间状态事件（形如 `HHMM activity` 的时间节点记录，例如 `0900study`）；升级后支持将单日事件流切分为连续的区间事件片（例如 `0900-1030study`）以输出成套的区间文本记录。
* 新增备注生成策略支持，允许在生成单点和区间事件时附带随机的备注后缀。

### 技术改进/重构 (Changed/Refactor)
* 重构事件流生成与文本渲染架构，解耦数据流和格式化渲染逻辑：
  * 引入内存语义单元 `GeneratedEvent` 和类型标志 `GeneratedEventKind`，用以表征事件生成的中间态。
  * 将文本行渲染逻辑解耦迁移至 `event_line_formatter.cpp`。
* 同步重构 `log_generator_unit_tests.cpp` 单元测试，添加对区间段渲染和格式的规则性断言测试。
