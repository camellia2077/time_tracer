# Naming Conventions

This document narrows ambiguous terms and lists preferred replacements.

## Stream-Style Recording

Avoid using `stream-style recording` as the primary term.

Use:

```text
point-event recording
```

`stream` can still appear as an explanatory synonym when discussing older
language:

```text
point-event recording, formerly described as stream-style recording
```

## Interval-Style Recording

Avoid using `interval-style recording` as the primary term.

Use:

```text
interval-event recording
```

Use `interval event` for one authored line, and `interval-event recording` for
the recording mode.

## Continuous

Avoid `continuous` when describing neighboring activity intervals.

Use:

```text
contiguous
```

`continuous` has mathematical meanings that are not intended by this project.
