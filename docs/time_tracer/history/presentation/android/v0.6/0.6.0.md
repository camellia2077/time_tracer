## [v0.6.0] - 2026-07-26

### 新增功能 (Added)
* 新增主题调色板定义 `ThemePaletteDefinition.kt` 与报告语义色彩映射 `ReportSemanticColors.kt`，扩展主题调色板体系，为 Report 统计图表、组成比例条与活动时间线提供多套语义化色彩配置。
* 新增 `ConfigSegmentedButton` 分段选择控件，优化外观主题、暗色模式与应用语言选项的交互体验。

### 技术改进/重构 (Changed/Refactor)
* 降级 Android SDK 最低支持版本，将 `apps/android/app/build.gradle.kts` 中的 `minSdk` 从 `35` (Android 15) 调整至 `29` (Android 10)，扩展应用兼容设备范围。
* 重构主题系统（Theme System），解决旧版仅指定“强调色 + 背景色”并依靠算法自动派生颜色导致复杂 Report 统计图表颜色数量不足、对比辨识度差的问题；新架构扩展为支持多组显式指定的语义色彩配置（Report Semantic Colors），为多元图表与可视化视图提供丰富的颜色集。
* 重构 Record 界面架构与卡片职责布局，按“高低频内容分离”与“单一入口单一动作”原则进行组件收纳与解耦：
  * **时间设置卡片 (`RecordTimeSettingsCard`)**：增加独立无动画折叠按钮，默认收起低频 Yesterday/Today 目标设置，保持核心当前时间始终可见，并支持折叠状态单独持久化。
  * **快捷入口卡片 (`RecordQuickAccessCard`)**：解耦卡片折叠与编辑模式按钮的重叠职责，折叠卡片时自动退出编辑态；移除系统预置活动与冗余提示文本，支持折叠状态持久化。
  * **编辑区与 Suggestions 归属迁移**：将 Suggestions 推荐活动从 `RecordInputCard` 迁移至快捷入口编辑区，集中维护快捷活动；使 Record Input 仅保留当前记录任务。
  * **Canonical 浏览器目标模式划分**：为 Canonical Activity Browser 引入显式目标上下文（`RECORD_INPUT` 填入输入框 vs `QUICK_ACCESS` 添加快捷项），针对不同入口应用独立标题与选择响应逻辑。
  * **TXT 实时预览 (`RecordTxtPreviewSheet`)**：合并 Marker 与 Day Block 渲染状态为单一完整更新状态，并将解析计算调度至 `Dispatchers.IO` 执行，消除 UI 中间态闪烁。
* 优化 Record 模式多语言展示文案与领域模型解耦表达，将旧版底层暴露的“区间事件 / 点事件 (Interval / Point)”调整为更自然面向操作的“计时 / 时间点 (Interval / Time point)”（日文为“計測 / 時点”），去除中日英文案中的上下文冗余系统词，且不修改内部 `RecordAuthoringMode.INTERVAL` 与 `RecordAuthoringMode.POINT` 领域模型。
* 重构 Config 设置屏幕组件结构，将外观设置面板拆分为 `ConfigThemePaletteSection`、`ConfigThemeModeSection`、`ConfigDarkThemeStyleSection` 与 `ConfigLanguageSection` 等模块化子项。
* 改进 Report 模块查询与图表渲染管线（`QueryReportViewModel` 与 `QueryReportChartPipeline`），优化图表参数绑定、空数据状态提示与组合图表绘制流程。

### 修复 (Fixed)
* 修复 SDK 最低版本降级至 Android 10 (`minSdk 29`) 后部分系统组件的语义色彩回落与 Surface 布局适应性问题。
* 修复 Record 界面在窄屏设备下快捷项拖拽网格与时间设定卡片的边距挤压和文案截断现象。
