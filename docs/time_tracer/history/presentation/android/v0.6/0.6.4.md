## [v0.6.4] - 2026-08-02

## 关联版本

* Core：`tracer_core v0.11.1`

本版本跟进 Core `v0.11.1` 的结束时间记录、报表统计和 canonical 配置语义，继续收敛 Android 与共享运行时的职责边界。

### 新增功能 (Added)
* 新增基于 Runtime 的 Quick Access 读写能力，将常用的活动名输入配置持久化到共享运行时，使用户导出/导入数据时可以一并迁移 Quick Access，无需在新设备或导入后重新添加，并在 Record 界面中实时同步更新。
* 新增 Report 平均值分母选项，支持按活跃天数或自然日计算组合统计，并将配置偏好持久化到用户设置。
* 新增 Android 调试数据库重建入口，支持开发和测试人员通过运行时命令从 TXT 数据重新构建数据库，用于验证 TXT 与配置变更后的重建结果。

### 技术改进/重构 (Changed/Refactor)
* 重构 Android 运行时配置资源边界，移除 APK 内置的 `config/program/**` 快照，复用仓库中的 `config/program/**` 作为唯一程序配置来源，避免 Android 运行时配置分叉或过期；可编辑配置仍保留在 `config/user/**`。
* 重构 Record 数据流与状态管理，适配 Core 的 `end_only` 记录，使只有结束时间的 point 记录能够正确保存、计入出现次数并排除在时长累计之外。
* 重构 TXT 编辑、导入与同步流程，在 activity hierarchy 合并、移动或改名后统一处理原始 TXT 内容、canonical/alias 替换结果和数据库重建，确保旧记录能够继续被识别并重新入库。
* 重构 activity hierarchy 编辑与迁移交互，复用 Core 提供的 canonical leaf merge 操作及其 TOML 更新、canonical replacement 和 alias replacement 结果，在 Android 侧完成配置、TXT 与数据库迁移的原子提交。
* 重构 Report 查询和图表渲染管线，复用 Core 返回的组合统计、活动树、平均值和每日状态语义；报告改为展示 Core 根据用户配置生成的活动层级状态，移除 Android 侧重复计算与固定 wake anchor 展示逻辑。
* 改进系统语言切换，使用完整 `LocaleList` 应用多语言环境，并同步更新中文、日文和英文文案。

### 修复 (Fixed)
* 修复 Android 运行时初始化、配置快照清理和导入导出流程对旧 APK 内置程序配置路径的依赖。
* 修复 Quick Access、TXT 编辑及 Report 空数据场景的状态同步和展示问题，避免无数据时图表、加载状态和提示文本不一致，并补充对应单元测试与界面测试覆盖。
