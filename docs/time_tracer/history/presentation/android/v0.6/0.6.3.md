## [v0.6.3] - 2026-07-30

### 关联版本
* Core：`tracer_core v0.11.0`

本次改动的核心目的是支持用户调整 activity 的 `parent` 归属。例如将 activity 的 `parent` 从 `computer` 修改为 `study`；修改完成后，查询结果中这些 activity 的归属会更新为 `study`。Core 负责处理 `parent` 变化及其对 canonical 和 TXT 数据的影响，Android 负责同步修改对应的 `activity_hierarchy/*.toml` 文件名，以保持文件名与 `parent` 一致；同时使用 `category` 替代 `hierarchy`，让 Android 配置编辑界面的分类操作更直观。

### 技术改进/重构 (Changed/Refactor)
* 重构 activity hierarchy 的 `parent` 修改流程，使用户可以将一组 activity 从一个 parent 归属调整到另一个 parent；后续查询和 report 会显示更新后的活动归属。
* 重构 Android activity hierarchy 编辑流程，在修改 `parent` 时同步重命名对应的 `activity_hierarchy/*.toml` 文件，保持文件名与 `parent` 一致，并完成 Core 返回的 canonical/TXT 更新结果。
* 重构 Android 配置编辑界面和 XML 文案，将不够直观的 `hierarchy` 统一替换为 `category`，改善分类、重命名和移动操作的用户表达。

### 修复 (Fixed)
* 修复 activity hierarchy 分类调整后 TXT 数据仍保留旧 canonical 的问题，改为同步重写 TXT、重建数据库，使 report 中的 activity 归属随分类变更更新。
