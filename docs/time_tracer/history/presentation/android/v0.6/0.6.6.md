## [v0.6.6] - 2026-08-07

### 关联版本

* Core：`tracer_core v0.11.3`

### 新增功能 (Added)

* 新增与 Core `ActivityHierarchy` 契约对应的展示模型，以及交换包专用的 `TracerExchangeSecurityLevel`、`TracerExchangeProgressEvent` 契约，减少 Android 自行维护 alias hierarchy 语义。
* 新增记录成功后的 hierarchy 创建反馈：当 Core 在记录活动时创建新的 hierarchy leaf 时，在记录状态中显示活动及其所属分类。

### 技术改进/重构 (Changed/Refactor)

* 将 Android alias editor、配置浏览、移动迁移、canonical catalog、TXT 记录映射和测试模型迁移到 `ActivityHierarchy`，统一消费 Core 的 hierarchy leaf mapping 与 replacement 结果；Android 只负责 UI、文件迁移和状态展示，不再重复实现 hierarchy 语义。
* 重构报告树结果渲染，将 tree 分支从通用报告分支中拆出，移除 presentation 层自行推导 canonical 路径的逻辑，改进节点层级、宽度、时长和占比进度展示。
* 将完整交换包从方向不明确的 `.tracer` 切换为加密 `.zip`，使非 TOML/TXT 导出内容更容易被用户识别并使用通用解压工具处理；同步更新 SAF MIME 类型、文件选择扩展名、默认文件名、密码文案及导入/导出服务调用，旧 `.tracer` 不再作为当前导入格式。
* 将交换包进度状态从通用文件加密进度迁移到 `TracerExchangeProgressEvent`；由于 ZIP 是整体交换包操作，UI 改为展示阶段级进度，不再展示逐文件进度，并简化导入取消、完成和失败状态传递。

### 弃用/删除 (Deprecated/Removed)

* 删除 Android 侧旧 `AliasEditorPresentationModels`、`FileCryptoGateway`、`FileCryptoProgress`、`FileCryptoSecurityLevel` 和 `RuntimeCryptoService`，改用 hierarchy 与 tracer exchange 专用契约。
