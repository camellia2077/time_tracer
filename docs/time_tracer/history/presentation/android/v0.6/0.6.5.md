## [v0.6.5] - 2026-08-04

### 技术改进/重构 (Changed/Refactor)
* 重构 Android Runtime contract，将原聚合式 `RuntimeGatewayModels.kt` 按 activity hierarchy、config、query、report、TXT、交换、诊断和运行时调用职责拆分为独立 contract 文件。
* 重构 Config 配置编辑状态与保存流程，将 `ConfigViewModel` 拆分为 UI state、alias 编辑器、移动编辑器、保存协调器和 factory，并将 alias 编辑对话框按基础操作、移动操作和动作操作拆分。
* 重构主题颜色模型，将调色板 token、预览颜色和报表颜色转换模型移到独立文件，统一各主题的报表颜色映射。
* 重构 Record/TXT 编辑器，将会话状态、底部操作面板、输入辅助、用例支持和界面组件拆分，并整理 interval 编辑、时间格式化和 wheel picker 的职责边界。
* 重构 Record 活动选择流程，整理 canonical catalog 的屏幕、分区和树形展示组件，复用独立的查询 contract 与 Record 用例支持。
* 重构 Report 查询与展示管线，将原 `QueryReportChartPipeline` 和集中式 ViewModel action 逻辑拆分为 chart/composition use case、presentation action、report action support 及独立的图表、树形、摘要和时间选择组件。
* 重构 Report 图表渲染职责，将热力图、组合统计选择器、树节点格式化和可视化辅助逻辑从页面组件中抽离，保持 UI 层只负责展示编排。
* 整理 Android 多语言资源与构建配置，补齐重构后配置编辑、Record 和 Report 界面所需的中文、日文文案，并同步清理过时的应用侧实现文件。
