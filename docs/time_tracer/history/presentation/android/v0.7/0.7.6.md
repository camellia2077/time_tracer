## [v0.7.6] - 2026-08-15

### 新增功能 (Added)
* 为 interval 新增一键采用上一条活动结束时间作为当前区间 `start time` 的操作，减少交替记录 interval 和 point 时的未记录间隔。
* 为 interval 新增全屏 elapsed 计时页面，使用双圆环展示小时与分钟循环进度，并以连续动画反馈学习或专注时长；Activity name 会显示在圆环上方。
* 在 Record Input 中显示最近一条活动的名称、开始时间、结束时间和持续时间，为上述 start time 调整提供可见依据。
* 新增 Android runtime 查询契约与 JNI 查询链路，复用 Core 提供的最近活动和活动尾部只读查询。

### 技术改进/重构 (Changed/Refactor)
* 统一 Android Record、runtime、查询结果和草稿状态中的时间字段为 ISO 本地时间 `HH:mm:ss`，TXT 持久化边界继续使用 `HHMMSS`。
* 将 interval 输入校验、时间轮选择器、持续时间计算和最新活动展示同步到 `HH:mm:ss`，并更新相关测试与多语言文案。
* 在 Record Input 中将最近区间展示为 `HH:MM-HH:MM`，同时保留精确到秒的持续时间显示。
* 将草稿、输入持久化和重复记录检测统一到 ISO 内部时间与 TXT 紧凑时间边界，避免不同格式直接混用。
* 对 Android runtime 查询响应增加 ISO 时间字段解析和范围校验，并在查询不可用或返回无效数据时安全降级。
* 同步更新 app、feature-record、runtime 的状态刷新链路和测试覆盖，确保逻辑日期切换、记录保存、查询结果展示及一键采用操作保持一致。
* 移除 interval 运行状态下冗余的计时器状态文本行，保留 elapsed 计时和操作按钮作为主要反馈。
* 为 interval 记录输入、规范化、校验失败和保存结果补充 `TimeTracerRecord` 日志，便于定位时间字段问题。
