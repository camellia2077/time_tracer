## [v0.7.11] - 2026-09-01

### 新增功能 (Added)
* 在 `Settings` tab 的 `App preferences` card 中新增 `Time display`，可选择 `24-hour` 或 `12-hour AM/PM`；设置会应用于 `Record Input` card、Record 当前时间和 Insights 活动时间线。
* 让 `Time display` 的 `12-hour AM/PM` 同步应用到 `Files` tab 的 `Editor` card 及其 day edit sheet 中显示的活动时间。
* 在 `Settings` tab 的 `App preferences` card 中为 `Page transition` 新增 `No animation` 选项。
* 在 `Appearance` card 的 `Theme Palette` 中新增 `Purple`、`Blue`、`Linen` 和 `Mint` 调色板；将 `Graphite`、`Teal` 和 `Amber` 分别调整为 `Grey`、`Green` 和 `Yellow`，并更新对应颜色方案。
* 为支持浅色/深色模式的调色板新增 `Light Surface Style`，可选择 `Neutral` 或 `Elevated`。

### 技术改进/重构 (Changed/Refactor)
* 将底部导航中的 `Config` tab 更名为 `Settings`，并同步重命名其直接关联的 Android 屏幕、资源、测试与文档入口。
* 将 `Page transition` 统一为单一的样式选择，移除独立的启用开关。
* 减轻浮动底部导航胶囊的阴影，使其在内容页上的层次更柔和。
* 将 `Appearance` card 的 `Theme Palette` 按 `Light/Dark Mode Themes` 与 `Fixed Appearance Themes` 分组折叠显示，并让预览随当前深浅模式同步。
* 将深色外观选项统一为 `Dark Surface Style` 的 `Neutral` 与 `Black`，提高 `Black` 模式下页面与卡片的层次区分。
* 优化 `Insights` tab 的 breakdown 层级导航，将 `Current level` breadcrumb 与 `Back to ...` 操作分组显示，并在层级操作与 breakdown 统计内容之间加入分割线。
* 让 `Current level` breadcrumb 支持点击祖先层级返回，收紧层级间箭头的间距并调整图标尺寸与颜色。
* 为 `Bar` breakdown 的每个活动条目统一使用 `outline` 中性边框，保持 `Time spent` 与 `Number of records` 下的行容器一致。
* 将 Android 构建与验证工具链更新至 API 37，同时保留 `minSdk = 29` 以继续支持 Android 10。

### 修复 (Fixed)
* 修复在 `No animation`、`Quick fade` 与 `Light slide` 之间切换时，`Page transition` 选项会意外折叠的问题。
* 修复浅色、深色及固定外观主题下 Android 手势导航区域被页面背景覆盖的问题，保持手势提示线及底部内容显示正确。
* 修复 `Record Input` card 全屏计时器的分钟圆环按秒跳动问题，使其按渲染帧连续推进。

### 弃用/删除 (Deprecated/Removed)
* 移除 `page_transitions_enabled` 偏好键；以 `page_transition_style` 的 `NONE` 取代关闭状态，且不保留历史 DataStore 值兼容读取。
* 弃用 `Graphite`、`Teal` 和 `Amber` 的旧 `theme_palette` DataStore 值；不提供兼容迁移，读取到旧值会回退为 `Indigo`。
* 移除旧的 `dark_theme_style` 偏好键，改用 `dark_surface_style` 和 `light_surface_style`；未设置新键时分别回退为 `Neutral`。
* 移除 `Bar` breakdown 根据最大时长或记录次数自动添加的选中描边与填充高亮，保留点击条目进入下一级活动层级的交互。
