## [v0.7.7] - 2026-08-17

### 关联版本

* Core：`v0.12.7`

### 新增功能 (Added)
* 新增 Insights 图表的活动范围层级选择器，支持浏览 `root_tree`、按根节点或子节点筛选，并在无记录窗口中保留完整层级供选择。
* 新增 Insights 图表当前周期与对比周期的切换、周期选择、折线/柱状图叠加展示及图例；支持日、周、月、区间和近期模式的上一周期对比。
* 新增图表统计摘要，展示活动总次数、总时长、平均每次时长、众数、中位数、完整时长范围、典型日时长范围、变异系数和平均绝对偏差。
* 新增年度图表按月聚合；区间超过 90 天时按月聚合，较短区间继续按日展示，并补充图表 Y 轴时长刻度和记录完整度信息。
* 新增 Android Insights 合同层的 `ActivityAggregate`，承载结构化 Insights 及周期活动视图使用的 Core 活动总时长和总次数。

### 技术改进/重构 (Changed/Refactor)
* 将 Insights 模式标签改为固定宽度、可水平滚动且打开时直接定位当前选项的 tab row。
* 将 Insights 结果显示模式从 `TEXT` 统一命名为 `DETAILS`，并将默认显示模式调整为详情视图。
* 取消 Android 端对旧版 Insights chart 统计字段的本地回退计算，要求核心 payload 提供必需的平均值、总量、活动日、区间日和分布统计字段，同时校验有限数值并归一化非负值。
* 使用 Core 返回的 `ActivityAggregate` 渲染周期活动总览和周期对比，避免再次累加 `activity_days` 导致统计口径偏差；composition 节点同步消费 Core 返回的单次平均时长。
* 将 Insights 图表根节点下拉菜单替换为可层级导航的全屏选择器，并将图表参数和周期对比控件拆分为可复用组件。
* 改进图表冷启动状态：等待 DataStore 展示偏好一次性恢复后再发起查询，避免默认详情结果覆盖已恢复的 Chart 结果；偏好恢复状态改由 ViewModel 统一管理。
* 将图表模式切换、统计摘要、周期活动对比和结构化结果解析同步到英文、中文和日文资源及对应测试。
* 将 TXT 结构化日编辑器的事件时间格式化改为复用 ISO `HH:mm:ss` 处理，修复已有 ISO 时间被重复插入分隔符的问题。
* 调整 Android Insights 模块依赖以支持 Compose 返回键处理，并扩展 Detekt 规则的 UI、运行时和测试目录排除配置。

### 修复 (Fixed)
* 修复 Insights 图表在缺少旧版统计字段时客户端自行推算、可能与 Core 统计口径不一致的问题。
* 修复 Record 全屏 interval 计时在息屏后恢复时重放已流逝分钟进度动画的问题，恢复后直接同步到当前进度。
* 修复 Record 全屏计时的小时进度圈在不足一分钟时提前显示进度的问题，改为按已完成分钟推进。
* 修复 Files 的 DAY 结构化视图加载期间短暂显示 Raw TXT 页面导致的闪烁，改为显示加载状态直至结构化内容就绪。

### 弃用/删除 (Deprecated/Removed)
* 删除依赖真机 `setContent` 和 Compose 语义树断言的 Record 仪器测试，并移除对应的 Android 仪器测试依赖与测试运行器配置。
