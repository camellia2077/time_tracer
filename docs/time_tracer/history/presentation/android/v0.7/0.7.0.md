## [v0.7.0] - 2026-08-10

### 关联版本

* Core：`v0.12.0`

### 技术改进/重构 (Changed/Refactor)
* 取消独立的 Data 与 TXT Tab，将数据管理、导入导出和 TXT 编辑入口归并到 Config 页面，复用原有数据与编辑会话能力。
* 将 Android 的 `feature-report`、契约、JNI/runtime delegate、transport codec 与测试入口统一迁移为 `feature-insights` 和 `Insights` 命名，并接入 core 的 temporal insights 协议。
* 将图表配色、平均值计算基准、展示模式与每日状态等 Insights 展示偏好迁移到 Android `DataStore`，由应用本地持久化管理。
* 将配置编辑与 TOML 导入/导出收敛为 Android 支持的 `user/behavior.toml` 和 `user/activity_hierarchy/*.toml` 白名单，保留原始配置编辑的 alias 工作流。
* 更新简中和日语的 Insights 用户文案，统一使用“分析”与“日次/每日状态”，并同步调整 Insights 页面、图表、主题和无障碍标签。
* 调整底部 Tab 的选中样式，保留加宽的强调色胶囊背景并禁用点击 ripple 消散动画。

### 修复 (Fixed)
* 修复覆盖安装后继续读取旧 `config/program` 的问题：每次启动覆盖 APK 托管的 `<filesDir>/config/program`，同时保留 `config/user`、数据库、TXT 和应用偏好。
* 修复旧 `report/reporting` 命名与新的 core insights 协议混用造成的 Android runtime、能力协商、错误响应和配置资源不一致问题。

### 弃用/删除 (Deprecated/Removed)
* 删除 `feature-report`、旧 `Report*` contract、`TemporalReportRequestJsonCodec`、report runtime delegate 及关联资源和测试，调用方必须使用 Insights 接口。
* 删除 Android 对 `config/user/charts.toml`、`config/user/heatmap.toml` 与 `config/user/insights.toml` 的打包、读取、写入、导入导出和兼容迁移；这些旧用户配置不再被 Android 识别。
