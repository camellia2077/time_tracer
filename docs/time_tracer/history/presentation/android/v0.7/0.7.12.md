## [v0.7.12] - 2026-09-10

### 关联版本

* Core：`v0.12.9`

### 新增功能 (Added)

* 在 `Files` tab 的 `Editor` card 的 `Edit time` 中，为 interval 提供 `Use ... as start time` 操作；仅使用同一逻辑日内上一记录的结束边界，首个无前置边界的 interval 不显示该操作，也不会跨日取值。
* 为 `Files` tab 的 `Editor` card 新增活动搜索，支持按 canonical path、canonical key 和 alias 进行不区分大小写的包含匹配，并保留命中活动的祖先层级。
* 为 `Files` tab 的 `Editor` card 增加 Core 委托搜索链路，通过 `ActivityHierarchyGateway` 和 Android runtime 调用 Core 的 `search_activity_hierarchy` 能力。
* 将 `Files` tab 和 `Insights` tab 的 `Edit day remark` 提升为全屏多行编辑页面，扩大长文本编辑区域并支持输入后自动保存。

### 技术改进/重构 (Changed/Refactor)

* 抽取公共 `ActivitySearchField`，统一 `Record Input` card 的活动搜索与 `Files` tab 的 `Editor` card 搜索框的单行输入、标签、形状、宽度和测试标识处理。
* 让 `Files` tab 的 `Editor` card 将搜索词和过滤结果作为独立展示状态管理，搜索结果不覆盖用户正在编辑的原始 TOML。
* 为异步活动搜索增加 query 与 TOML 内容快照校验，避免旧请求返回后覆盖新搜索或新文件的结果；统一由状态变化触发搜索，避免同一次输入重复请求 Core。
* 调整 `Record Input` card 的 interval 摘要，直接显示时间范围和持续时间，并根据 `Settings` tab 的 `Time display` 设置显示 12-hour 或 24-hour 时间。
* 精简 `Record Input` card 的 interval 辅助信息；仅在当前 interval 开始时间不同于上一活动结束时间时显示 `Use ... as start time` 操作。
* 统一 `Insights` tab 的 `Details` 和 `Chart` 的 `Date selection` card，复用可折叠日期选择布局及 day/week/month 的直接次级选择页面。
* 抽取共享 `FullscreenTextEditor`，让 `Files` tab 和 `Insights` tab 的 `Edit day remark` 复用相同的全屏布局、主题卡片背景色、键盘避让和文本编辑行为。
* 将 `Edit day remark` 改为防抖实时保存，移除 Save 操作；已有文本打开时不自动聚焦，避免初始光标出现在首字符前。
* 统一 `Settings` tab 的 `Data management` 卡片标题与内部小节标题，使用主题强调色保持标题层级一致。
* 将 wake alias 从 `activity_hierarchy/sleep.toml` 和 `sleep_inference.wake_keywords` 的重复配置迁移到 `behavior.toml` 顶层 `[canonical]`；Android 只提供配置资源并通过 Core 使用其语义，普通睡眠活动仍由 `activity_hierarchy/sleep.toml` 管理。

### 修复 (Fixed)

* 修复在 `Files` tab 的 `Editor` card 删除当前最新活动后，`Record Input` card 的 `Last` 仍显示已删除活动的问题；TXT 同步数据库完成后会重新查询最新活动并显示删除后的实际最新记录。
* 修复快速输入或切换文件时，旧的异步活动搜索结果覆盖当前搜索状态的问题。
* 修复切换 `Files` tab 的 `Editor` card 文件后沿用旧搜索词的问题；重新打开同一文件时保留当前搜索状态。
* 修复 `Record Input` card 的 `Use ... as start time` 可能使用跨午夜活动结束时间的问题，使该操作始终取当前逻辑日内作者最后记录活动的结束时间。
* 修复 `Insights` tab 的 `Details` 在选择 day/week/month 时多弹出一层无效的 `Select day` 抽屉，使其行为与 `Chart` 一致并直接进入次级日期选择页面。

### 弃用/删除 (Deprecated/Removed)

* 删除 Android 默认 `behavior.toml` 中独立维护的 `sleep_inference.wake_keywords`，改由顶层 `[canonical]` 中的 alias 自动生成 wake 集合。
* 删除 `activity_hierarchy/sleep.toml` 中重复维护的 wake alias；Android 不再本地解析 alias 映射、推导 wake 集合或判断睡眠语义。
