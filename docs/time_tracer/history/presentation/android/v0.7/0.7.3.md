## [v0.7.3] - 2026-08-12

### 关联版本

* Core：`v0.12.3`

### 新增功能 (Added)

* 在 Insights 的日时间线中新增日备注与活动备注的结构化编辑入口，保存后刷新格式化结果。
* 为 Files 的日记录新增 `structured` 与 `raw TXT` 视图切换；结构化视图支持编辑时间、活动、日备注和活动备注，并可从活动目录选择活动。
* 将 Record 快捷活动的编辑移入底部抽屉，避免编辑设置占用记录表单空间。

### 技术改进/重构 (Changed/Refactor)

* 统一 Insights 构成图的调色板排名逻辑；优化 Treemap 前三项布局以便快速比较，并将前四项时长固定显示为 `d h m` 格式。
* 将 Files、Insights Timeline 和 Record Input 的多行备注编辑统一为底部抽屉，提供保存与取消操作并保留单行摘要。
* 将 Record Input 的备注区域改为固定高度的轻量入口行；空备注显示 `+`，已有备注显示编辑图标，不再随多行内容撑高表单。
* 将 Files 的原始 TXT 编辑器从底部抽屉改为页面内编辑，并保留撤销、重做和保存操作。
* 将 Record 的区间时间编辑统一为时、分、秒滚轮选择。
* 为 Config 与数据管理卡片增加可持久化的展开/折叠状态。
* 将底部导航顺序调整为 `Files`、`Insights`、`Record`、`Config`。
