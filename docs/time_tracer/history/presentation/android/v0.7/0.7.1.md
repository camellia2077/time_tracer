## [v0.7.1] - 2026-08-10

### 关联版本

* Core：`v0.12.1`

### 新增功能 (Added)
* 为 `day`、`week`、`month`、`year`、`recent` 和 `range` 提供独立的 Insights 自定义状态配置、报告显示模式和状态编辑入口。
* 在状态编辑器中显示父活动的次数和累计时长，并在保存后重载运行时及刷新当前报告。
* 为 Markdown 预览增加单个 `*` 斜体标记渲染，同时保留未闭合标记的原始文本。

### 技术改进/重构 (Changed/Refactor)
* 将 Android Insights 状态配置迁移到 `DataStore`，并在 JNI 初始化时以 JSON 注入运行时，不再依赖 `user/insights.toml`。
* 将 structured Insights 状态值统一为 `InsightsStatusValue`，支持日和范围报告的次数、累计时长统计。

### 修复 (Fixed)
* 修复 week、month、year、recent 和 range 的结构化状态统计未传递到编辑器的问题。
* 修复 Tracer 导出包含 Android 不再使用的 `user/charts.toml`、`user/heatmap.toml` 和 `user/insights.toml` 的问题。
