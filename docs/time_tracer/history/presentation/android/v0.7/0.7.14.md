## [v0.7.14] - 2026-09-21

### 关联版本

* Core：`v0.12.10`

### 新增功能 (Added)

* 为 `Files` tab 的数据导入支持普通 exchange 目录；目录缺少 `manifest.toml` 时仍可继续导入，同时继续支持加密 ZIP 导入。
* 让 `Files` tab 的 TXT + TOML 普通目录导出与 ZIP 导出使用一致的 exchange 目录结构，均包含 `manifest.toml`、`config/user/**` 和 `payload/**`，并统一使用 `data_YYYY-MM-DD_HH-mm-ss` 命名，以便区分导出时间并避免覆盖之前的导出数据；ZIP 使用 `.zip` 后缀。
* 为 `Insights` 中的活动分类增加 Android DataStore 颜色偏好，选择内置颜色或删除颜色后立即保存，并用于活动时间线展示。
* 新增 `Record` tab 的 `Quick Access` card 管理模式；已有快捷活动时可通过铅笔图标进入管理模式，点击活动右侧的关闭图标将其删除，完成后通过对勾退出，并在最后一个活动被删除后自动结束管理模式。

### 技术改进/重构 (Changed/Refactor)

* 暂缓修复 `Record` tab 的 `Record Input` card 中 `Interval` 全屏计时动画的息屏恢复显示问题：重新亮屏时，进度圆弧会短暂变淡，随后很快恢复为当前进度对应的主题颜色。该问题尚未解决，仅涉及动画显示，因定位和修复难度较高，暂不继续修复。
* 统一普通目录与 ZIP 导出的时间命名规则，并让纯文本导出 materialize 为独立的 `data_YYYY-MM-DD_HH-mm-ss/` 目录，使其目录结构与 ZIP 解压结果一致，用户可以直接复制整个目录而无需单独选择 `payload/`、`config/` 和 `manifest.toml`。
* 将 Android 导入导出流程中的英文、中文和日文密码文案改为面向用户的表述，明确导出时设置导出密码、导入时输入导出密码，避免使用 `Encrypt Password`、`Decrypt Password` 等技术化表述造成理解偏差。
* 将活动分类颜色从 activity hierarchy TOML 和 Core runtime contract 收回 Android presentation，因为颜色只影响 `Insights` 展示、不参与活动解析或业务逻辑；由 DataStore 保存展示偏好，减少 Core/TOML 写回链路并使修改和保存更直接。
* 统一纯文本目录导出与 ZIP 导出的文件格式和目录层级，确保两种导出结果可以由同一套 exchange 导入逻辑处理，避免因 carrier 不同而分开维护导入路径。
* 将 Android 数据导入导出相关的 manifest 生成、目录结构和 exchange 内容构建交由 Core，presentation 只负责 SAF 文件选择、目录读写和界面流程。
* 删除旧的 `DataFolderSnapshot` 导入链路，统一通过 `TracerExchangeGateway` 调用 Core exchange 能力。
* 将 `Record` tab 的 `Quick Access` card 顶部操作拆分为管理、添加和折叠：使用中性色 `+` 打开 `Add to Quick Access` sheet，仅在已有快捷活动时显示管理入口，并在管理模式中将铅笔切换为主题色对勾；空状态同步改为引导用户点击 `+` 添加活动。
* 将 `Add to Quick Access` sheet 中的两个入口统一为带说明性图标和操作文案的触控项：使用 `Add from frequent activities` 和 `Add from activity catalog`，并收紧入口间距和高度以减少冗余留白。
* 为嵌套全屏页面增加独立的 dialog 层，并让 `Add to Quick Access` 中打开的 `Frequent` 和 `Activities` 页面显示在父页面之上。
* 将 `Add to Quick Access` sheet 和 `Quick Access` 管理模式改为互斥的临时界面状态；从折叠状态进入任一操作时自动展开 card，折叠 card 时自动退出这些临时状态。
* 将中文和日文 `Insights` 相关用户文案统一为“统计”/`統計`，并同步统计结果、统计错误、统计设置和无数据状态的表述。
* 在 Android runtime 配置校验成功后预先创建空的 ingest 数据库 schema，使应用启动后数据库存在但没有记录时可以正常返回空结果；同步更新 Android runtime smoke tests 覆盖空数据库查询。

### 修复 (Fixed)

* 修复分钟内圈换圈时在 60 秒处短暂停顿的问题，让新一圈立即开始，并让上一圈平滑淡出。
* 统一 interval 全屏计时器内外圈的端点样式为平头，使进度边界与实际时间一致。
* 修复 `Record` tab 的 `Quick Access` card 中从 `Add to Quick Access` 打开 `Frequent` 或 `Activities` 时，子页面被父页面覆盖的问题。
* 修复 `Insights` 在数据库为空或统计结果为空时将正常无数据状态显示为错误的问题；图表、分布图和结果摘要现在显示无数据状态。

### 弃用/删除 (Deprecated/Removed)

* 删除 Android 侧通过 `set_parent_color` 修改 activity hierarchy TOML 的调用链，颜色选择和删除不再触发 Core TOML 写回。
* 删除 `Quick Access` 添加面板可见状态的 Android DataStore 键 `record_quick_access_editor_visible` 及其读写链路；仅继续持久化 card 的展开状态，添加面板和管理模式不再跨会话恢复。
