## [v0.7.5] - 2026-08-14

### 关联版本

* Core：`v0.7.5`

### 新增功能 (Added)
* 新增活动层级父分类颜色配置：支持直接输入 HEX 颜色（自动处理 `#`、大小写和缺失位补 `0`）、颜色预览与清除，并提供按 CSS 标准命名颜色划分的全屏色系选择器。
* 新增 Insights 活动时间线的父分类颜色条，在时间文本左侧显示已配置颜色，让用户无需逐条阅读活动文本即可快速辨识当日活动类型。
* 新增 Record 活动浏览器 `Tree`、`Frequent`、`Categories` 来源选择的 DataStore 持久化，重新打开后保留上次选择。
* 新增“记录未配置活动时提示”设置，默认关闭并通过 DataStore 持久化；开启后，记录未配置活动前显示说明对话框，确认后继续记录并完成活动配置。

### 技术改进/重构 (Changed/Refactor)
* 扩展 Android 活动层级、运行时 JSON 编解码与结构化 Insights 契约，传递可选 `color` 和 `parent_color` 字段，并支持以 JSON `null` 清除父分类颜色。
* 将父分类颜色编辑、CSS 调色板与输入规范化逻辑集中至 `ActivityHierarchyParentColorEditor`，保持层级编辑卡片的职责聚焦。
* 将未配置活动的记录确认逻辑集中在 Record 输入流程中，统一点记与区间记录的确认后执行路径，并使用问号图标按需展开设置说明。
