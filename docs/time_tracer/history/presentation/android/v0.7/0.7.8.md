## [v0.7.8] - 2026-08-22

### 关联版本

* Core：无关联变更；本次仅涉及 Android UI、交互、偏好存储与验证工具，不改变 Core 业务逻辑、数据模型或契约。

### 新增功能 (Added)
* 新增 Insights `层级` 显示模式，将 Details 中的`Breakdown`活动树与层级深度选择移入该模式；详情以活动和时间顺序为主，图表继续专注图表展示。
* 新增 Insights 活动概览的前周期对比显示设置，支持绿色/红色、红色/绿色、主题强调色/灰色和蓝色/橙色配色，以及方向箭头、趋势线和正负号三种变化指示符；选择会持久化。
* 新增主页面切换设置，可启用或关闭切换效果，并在快速错峰淡入淡出和轻微左右滑动之间选择；选择会持久化。
* 新增 `android-test` 子命令，可按 Android 模块运行全部或指定的 debug 单元测试，并支持重复传入 `--tests` 筛选类或方法。
* 新增第三方许可证页面的库搜索和无结果提示，并充分利用底部导航上方的可用空间，减少列表下方空白。

### 技术改进/重构 (Changed/Refactor)
* 重构 Files 数据管理页为导入、导出和维护分区的操作卡片；将压缩包导出、加密强度和危险操作收纳为可展开的层级，保留明确的不可逆操作提示。
* 重构 Config 为可展开的设置层级：主题模式、主题配色、Insights 图表样式、活动对比和平均日口径在折叠时显示当前选择摘要，并保存展开状态。
* 重构 About 为`项目详情`和`第三方许可证`两个入口；将复制诊断信息放入`项目详情`，并统一入口卡片与子页面的视觉层级。
* 重构底部 Files、Insights、Record、Config 导航：未选中时使用描边图标，选中时使用主题色填充图标和包含图标、文字的浅强调色胶囊；胶囊以 140ms 跟随切换。
* 重构主页面切换，保留各 tab 的页面状态，避免切换回来后重置；快速淡入淡出总时长约 180ms，左右滑动仅移动页面宽度的十六分之一。
* 将 Record 常用活动的回看天数和 Top N 输入移入常用活动目录；在目录可见时修改偏好会立即刷新，并取消过期查询以避免旧结果覆盖新设置。
* 为新的导航、设置、Insights、Record 行为补充 Robolectric 与 ViewModel 覆盖，并同步英文、中文和日文文案。
* 将 Android Lint 改为以 `apps/android/app/lint-baseline.xml` 过滤既有问题且将新增 warning 视为错误，建立合并前零新增 Lint warning 的校验口径。

### 修复 (Fixed)
* 修复 HyperOS 首次安装或覆盖更新后，最近任务预览可能将 `Tracer` 回退显示为 `com.example.tracer` 的问题：在 Manifest 中使用固定应用标签，并在 `MainActivity` 初始化时同步任务描述标签。
* 修复关闭页面切换效果后仍短暂组合离场页面、导致新页面闪烁的问题；关闭时直接渲染目标页面。
* 修复 Insights 选择层级模式、切换分析周期或恢复持久化展示偏好时未稳定加载活动树的问题。
* 修复 Insights `insights_summary_no_data_body` 的中文和日文格式参数缺失，消除 `StringFormatCount` Lint warning。

### 弃用/删除 (Deprecated/Removed)
* 删除 Insights Details 内的`Breakdown`参数分区，改由独立的`层级`显示模式承载活动树。
* 删除 Record 常用活动加载中的占位文案，保留已有活动列表直至刷新完成，避免列表闪烁。
