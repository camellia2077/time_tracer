## [v0.5.1] - 2026-07-06

### 新增功能 (Added)
* 新增 `.tracer` 数据备份包导入/导出与传输管理面板（`TracerScreenExports.kt` 与 `TracerScreenTomlImport.kt` 等）。支持将整套数据库及相关配置以安全加密的 `.tracer` 包格式导出、分发及完整导入恢复，提供面向用户的数据导入确认与传输过程进度反馈。
* 新增文件夹导入配置功能，支持在数据管理页选择并递归导入 `.toml` 配置文件到 runtime 存储区。
* 新增当前 TXT 记录文件的 ZIP 备份导出选项，支持将当前选中的月度记录打包导出为 plain ZIP 压缩包以便于分享或备份。
* 新增 suggestions (自动建议) 的 `RecordSuggestionOutputMode` 输出模式设置项，并将 suggestions 交互层由原本的底部抽屉升级为全屏 `Activity Picker` 界面（以便于容纳并展示大量且较长的 canonical 与 alias 建议项）。用户可在标准规范名模式（显示如 `study_math_calculus` (canonical) 等层级活动路径）与别名模式（显示如 `数据结构` (alias) 等别名）之间进行切换，以选定对应的格式作为添加新记录的输出，并支持该模式设置的本地持久化。
* 新增 APK 构建复制机制，构建 release 时在保留 `app-release.apk` 的同时，额外复制并生成统一命名的 `TimeTracer-release.apk` 到 `apps/android/app/build/outputs/final-apk/release/` 目录。
* 新增 `DestructiveActionStatusText` 统一状态文案结构。针对 Clear All Data、Clear TXT、Clear Database 等危险操作，将先前过于偏向 debug 风格的原始提示（如直接展示底层路径、原生 JSON 响应等）重构为面向最终用户的“运行中/成功/失败”三段式状态。

### 技术改进/重构 (Changed/Refactor)
* 优化 Suggestions 配置入口，将建议所用的 `lookbackDays` 和 `topN` 属性从 Quick Access 快捷卡片折叠区迁移并解耦到 Suggestions 设置面板中。
* 优化建议设置的校验机制，放宽对 `lookbackDays` 与 `topN` 的输入框限制，允许输入框在修改期间被临时清空（此时数值临时为 `0` 或空），并支持将二者设为 `0` 以表达不想显示任何 suggestions 筛选结果的合法诉求。通过对齐底层核心库新增的“直接跳过数据库查询”语义，彻底解决了因以前校验过严导致用户在清空数字再键入新值时输入被拦截的交互痛点。
* 优化 Suggestions 界面刷新机制，在全屏 `Activity Picker` 开启时，修改 suggestions 参数（`lookbackDays` 或 `topN`）会立刻重新触发本地查询，无需重新打开 Picker。
* 统一 Android app 应用名称为 `Tracer`，将 `values/strings.xml`、`values-zh/strings.xml` 及 `values-ja/strings.xml` 里的 `app_name` 改为固定不翻译的 `Tracer`。
* 重构 TXT 选项卡 (TXT tab) 中卡片的 `open-day` 状态准备与加载逻辑，收敛至统一的“单一 open-day 准备策略函数”，添加注释并理顺相关测试入口，以解决之前因 debug 逻辑在交互中插入过多冗余行的问题。
* 同步更新 release device smoke 验证所引用的 APK 文件路径、相关文档说明及对应的 Python 测试用例。

### 修复 (Fixed)
* 修复 suggestions 因 libs 缺乏反向转换支持而无法使用的错位问题。此前 libs 仅支持单向的 alias 转换为 canonical 映射（例如从 `数据结构` (alias) 转换为 `study_computer_data_structure` (canonical)），当建议项携带完整的层级活动路径 (canonical) 返回时，安卓表现端无法反查回填对应的别名 (alias) 以匹配原有录入流程。本轮修改中，安卓端通过调用 libs 新增的 `listActivityAliasMappings()` 获取映射关系，成功建立了 `study_computer_data_structure` (canonical) -> `数据结构` (alias) 的反查回填机制；并随后消费 libs 直接支持 canonical 文本录入的新特性，实现建议项直接进入后续 authoring 和 parsing 流程。
* 修复点击建议项（suggestion）后浮层面板未能正常收起，以及由于隐藏与 toggle 路径冲突导致的面板二次弹开问题。
* 修复底部 tab 导航栏底部的纯色横条视觉问题，在 `TracerScreenShell.kt` 中将原先的 `Scaffold(bottomBar = ...)` 替换为全屏 `Box` overlay 布局，使页面内容得以延伸到最底端，并将底部导航栏作为半透明悬浮层绘制。
* 修复 `SnackbarHost` 与悬浮导航底栏互相遮挡的问题，将 snackbar 定位调整至导航栏上方，且保留导航底板的圆角、阴影与安全区 padding。
* 修复 TXT 编辑器中删除最后一行为“时间+活动”的记录行（例如删除 `0800study`）后再键入新行进行插入时，因 open-day 准备状态不一致导致抛出 `saved blocked / Date month '01' does not match month header '06'` 脏状态错误的问题。原因是在执行单日视图编辑（即显示和修改整月文本文件中特定某一天的“窗口”数据）时，由于交互导致临时 month 状态退回到默认占位符，从而加载了不匹配的日期。此问题通过引入统一的“单一 open-day 准备策略函数”来合理决定是否复用现有有效 ISO 日期，以及通过 `choosePreferredMonthContent` 过滤掉不合法的内存占位内容来解决。
* 修复冷启动后进入 TXT 页面首次点击 "Show Content" 会出现空白弹窗，直到第二次点击才刷新出内容的加载不同步问题。
* 修复危险操作状态显示不友好的问题，避免在 Clear All Data 等操作时将底层的 debug 路径或 native 原始 JSON 响应直接显示在 UI 上。
