## [v0.5.2] - 2026-07-16

### 新增功能 (Added)
* 新增报告界面显示偏好持久化，保存用户选择的报告结果显示模式、报告参数分区以及图表语义模式；下次进入报告时恢复上次选择，避免每次回到默认选项后重复切换。
* 补充 alias TOML 配置管理界面，除原有编辑能力外，支持在 `converter/aliases/` 下创建和删除结构化映射文件、自动维护 `alias_mapping.toml` 的 includes 列表，并在删除前提示历史记录解析风险。
* 新增数据库重建流程，重新读取 TXT 数据和 TOML 配置进行解析，将解析结果重新插入或更新到数据库，并以运行中、成功、失败三种用户可读状态反馈结果。
* 以 TXT/TOML 文件夹导出替代旧的 TXT ZIP 导出，提供不压缩、不加密的文本传输方式；同时导出全部可用 TXT 月份及其解析所需的 runtime TOML 配置，避免只有 TXT 而缺少配置导致无法解析并写入数据库。
* 新增 TXT 年月选择器及可用月份展示，支持在 TXT 页面按年份和月份切换当前记录文件，从而编辑指定月份的 TXT 内容。
* 新增记录建议选择器和快捷活动入口，支持从规范化活动目录选择记录，并改善记录页的快速输入流程。
* 新增原始 TXT/TOML 配置导入流程及 ZIP 备份导入支持，用于恢复未压缩导出的数据和运行时配置。

### 技术改进/重构 (Changed/Refactor)
* 重构报告查询与展示流程，统一 report、stats、tree、chart 和 composition 的参数输入、结果解析及页面路由，适配 Core 新的统一 query 响应与加权项目树结构。
* 完成 Pie/Treemap 的多层级下钻展示：消费 Core 提供的加权 activity tree，用户点击 root 或子节点后切换当前层级，查看被选节点下一级的持续时间比例；同时让饼图、横向条形图和 treemap 按活动排名分配颜色与展示层级。
* 重构 runtime 查询消息解析、gateway DTO 和初始化流程，移除 Android 侧对旧 tree 查询接口及 legacy data-query 适配层的依赖。
* 重构配置浏览与编辑页面，按 converter、charts、meta、reports 分类列出 TOML 文件，支持结构化 alias 编辑、父级选择、自动保存及运行时重新初始化。
* 重构 TXT/Tracer 导出和文件树写入流程，将输出编排从当前选中文件扩展为 TXT 与 TOML 多文件导出，并统一处理读取、创建目录、写入和失败状态。
* 修复底部浮动导航的布局问题，移除 tab 栏下方的纯色图层，避免 tab 遮挡页面内容，并为滚动内容补充底部安全空间，使页面拖动到底部后仍可继续查看被遮挡区域。
* 统一配置删除、数据库重建、数据导入等危险操作的状态文案和 runtime 调用路径，提供一致的进度与错误反馈，并避免将原始 native 错误直接展示给用户。
* 增加 canonical activity catalog 查询及记录输入、查询参数和运行时映射支持，使建议项与配置中的规范活动保持一致。
* 重构记录页状态、TXT 编辑器生命周期和导入协调器，统一草稿、持久化和运行时更新流程。

### 修复 (Fixed)
* 修复报告查询和 Markdown 生成状态被重复显示为全局状态提示的问题，将结果与进度交由报告内容区域展示。
* 修复 composition 图表按 root 名称计算颜色导致排序变化时颜色不稳定的问题，改为按当前显示排名分配调色板颜色。
* 修复配置文件创建、删除及 alias includes 更新后的列表刷新和 runtime 重载状态处理，避免文件已经变更但界面或运行时仍使用旧配置。
* 修复 TXT 与配置导出在无可用文件、读取失败、目标目录创建失败或写入失败时的错误反馈和进度统计。
* 修复记录建议、TXT 编辑和配置导入过程中的状态同步及页面刷新问题。

### 弃用/删除 (Deprecated/Removed)
* 删除 Android 侧旧的独立 tree 查询 gateway、runtime bridge 和 legacy adapter 接口，统一通过 Core 的 runtime query action 获取树结果。
