## [v0.5.0] - 2026-06-18

### 新增功能 (Added)
* 新增区间记录（Interval Recording）记时模式与对应交互界面，允许移动端用户输入起止时间范围或使用计时器进行区间管理。
* 新增 `missingWakeAnchor` 属性的 JNI 逻辑传递与本地数据持久化配置（`RecordInputPersistence`）。

### 技术改进/重构 (Changed/Refactor)
* 升级适配 `NativeBridge` 与 `NativeRuntimeBridge` 的 JNI 桥接交互协议，完美桥接并消费上游核心层 `libs/tracer_core` 在 `v0.10.2` 中引入的最新区间处理能力。
* 统一同步移动端内置的 Markdown 报告样式配置模版（`day.toml`、`month.toml` 等），使安卓端输出与核心引擎对齐。
* 重构时钟注入逻辑与本地相关单元测试，消除跨时区 Runner 执行环境的脆弱性，保障 GitHub Actions Android CI 基线通过。
