## [v0.5.3] - 2026-07-23

### 新增功能 (Added)
* 扩展既有的结构化 alias 编辑器，支持将 alias 升级为 group、把 alias 移动到已有层级，以及预览并确认层级迁移；本次同时移除旧的 `alias_mapping.toml` 选择和索引管理，仅保留固定 `aliases/` 目录下的结构化编辑。具体迁移过程如下：

  ```toml
  # 初始状态
  parent = "exercise"

  [aliases]
  "有氧运动" = "cardio"
  "跑步" = "running"
  ```

  * 有氧运动 → `exercise_cardio`
  * 跑步 → `exercise_running`

  **1. 将“有氧运动”升级为活动分类**

  ```toml
  parent = "exercise"

  [aliases]
  "跑步" = "running"

  [aliases.cardio]
  group_aliases = ["有氧运动"]
  ```

  升级后，分类自动继承原活动名作为自己的记录名称。

  * 有氧运动 → `exercise_cardio`
  * 跑步 → `exercise_running`

  虽然 TOML 结构改变，但 canonical 与层级未改变；第 1 步不需要 TXT 或数据库迁移。

  **2. 将“跑步”移动到 `cardio` 分类**

  ```toml
  parent = "exercise"

  [aliases.cardio]
  group_aliases = ["有氧运动"]
  "跑步" = "running"
  ```

  * 有氧运动 → `exercise_cardio`
  * 跑步 → `exercise_cardio_running`

  “跑步”的 canonical 发生改变；第 2 步需要替换 TXT 中的旧 canonical，并重建本地数据库。
* 通过上述层级迁移保持 alias 配置、TXT canonical 内容和加权项目树数据一致：仅改变 TOML 结构时保留现有数据，canonical 发生改变时才执行 TXT 替换和数据库重建。
* 新增记录页 interval 计时流程，额外保存起止时间的日期，并统一按 start 日期将区间记录写入对应 TXT 文件；支持开始、停止、编辑起止时间、查看归属日期、保存草稿和放弃未保存区间记录，避免前一天晚间开始的记录在次日保存时被错误归档到当天，也覆盖跨天睡眠等活动的归档场景。
* 新增报告 Timeline 展示与备注编辑，支持用户在查看活动 Timeline 的同时直接修改日期备注和活动备注，并在保存后即时更新当前页面内容，避免为了修改备注切换到 TXT 页面，使查看与修改保持在同一功能上下文内。
* 新增项目树的层级化展示、按时长排序、持续时间占比、canonical 路径和可滚动布局，帮助用户理解活动在项目树中的层级、时长占比和 canonical 路径，并按 Core 返回的最大深度控制当前显示层级。
* 新增报告页面显示状态持久化，保存报告模式、结果显示模式、参数分区、树层级和图表显示偏好，避免用户每次进入 Report 都重新选择这些设置。

### 技术改进/重构 (Changed/Refactor)
* 重构 Android runtime 与 gateway 适配层，消费 Core 的活动名称转换、canonical 名称替换、活动/日期备注原子更新和新的报告查询响应，避免在 Android 侧重复实现 Core 语义。
* 重构 alias 配置管理，移除 Android 侧对 `alias_mapping.toml` includes 列表的手工维护，改为在固定的 `aliases/` 目录中管理结构化 alias 和 group 文件；其他配置仍保留 `[converter]` 业务分区。
* 重构报告查询状态与参数流程，统一 report、tree、chart、heatmap 和 Timeline 的查询状态，参数完整且有效时自动刷新，并在重新进入报告页时重新读取当前数据，解决用户在 Record 页面修改数据后返回 Report 仍显示旧缓存的问题。
* 重构报告结果展示，移除独立 Stats 查询卡片，将无数据状态、树查询、Markdown 报告和图表结果纳入统一的报告页面流程。
* 优化 TXT 编辑器会话、草稿和 runtime 同步生命周期，支持多行备注、月份文件刷新以及 alias 配置变更后的 TXT 和数据库状态同步。
* 更新 Android runtime 配置快照、C ABI/JNI 适配、协议模型、多语言文案和相关单元测试，保持 Core 新配置结构与报告语义在 Android 端一致。

### 弃用/删除 (Deprecated/Removed)
* 删除 Android 侧独立的 Stats 查询模型、参数卡片、状态处理和对应测试，避免独立 Stats 卡片与日报中的 project breakdown 内容重复。
* 删除 Android 侧对旧 alias 索引文件增删 includes 的兼容逻辑，改用 `aliases/` 目录下的配置文件生命周期管理。
