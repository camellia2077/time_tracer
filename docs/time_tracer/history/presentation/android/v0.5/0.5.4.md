## [v0.5.4] - 2026-07-24

### 新增功能 (Added)
* 新增报告 Markdown 语言传递链路，根据应用当前语言向 Core 请求 `en`、`zh` 或 `ja` 报告文本，并在语言切换后重新查询当前报告。
* 扩充 `exercise.toml` 的活动层级，新增 cardio 下的游泳、骑行和跑步分组，以及 strength-training 下的蹲、推、拉分组和常见训练动作，同时保留围棋、瑜伽和普拉提等根级 alias。
* 扩展 Android 配置 bundle 清单，纳入 Markdown 报告的 `en`、`zh`、`ja` 五种报告配置文件。

### 技术改进/重构 (Changed/Refactor)
* 重构报告查询状态，使语言变化更新 Core 报告 locale 并复用当前选择重新加载结果，不再只切换 Android UI 文案而保留旧语言的 Markdown 内容。
* 更新报告请求模型和 JSON 编解码，为查询和导出请求统一增加 `locale` 字段。
* 更新 Android runtime 配置快照和报告 TOML，保持 alias 层级、活动统计标签及多语言报告资源与 Core 配置一致。

### 修复 (Fixed)
* 修复应用语言切换时 Activity 重建造成的短暂黑屏，通过 `AndroidManifest.xml` 的 `configChanges` 保持主界面状态并让报告内容平滑刷新。
* 修复通过 SAF 覆盖导出 `.tracer` 文件时旧 ciphertext 尾部残留导致加密 payload 长度不匹配的问题；相较于仅写入的 `w` 模式，改用会在写入前截断文件的 `wt` 模式，确保较短的新密文不会混入旧数据。
