## [v0.4.7] - 2026-08-02

## 关联版本

* Core：`tracer_core v0.11.1`

本版本跟进 Core `v0.11.1` 的 canonical 配置、结束时间记录和报表查询语义，扩展 Windows CLI 的层级迁移与日期校验控制能力。

### 新增功能 (Added)
* 新增 `activity merge` 命令，将一个非 group 的 leaf activity 合并到另一个非 group leaf，删除源 activity 及其 aliases，并同步替换 TXT 中旧的 canonical/alias 内容、重建数据库，使历史记录继续归属于保留的 activity。
* 为 `pipeline convert`、`pipeline ingest` 和 `pipeline validate` 新增显式 `--date-check` 与 `--no-date-check` 参数，支持在命令行选择 `none`、`continuity` 或 `full` 日期校验模式，其中 `--no-date-check` 是选择 `none` 模式的快捷写法。

### 技术改进/重构 (Changed/Refactor)
* 重构 alias 命令及配置文件术语，将 TOML 根表从 `aliases` 统一更名为 `canonical`，同步更新树展示、移动、重命名、迁移和帮助文本。
* 重构 canonical/alias 迁移事务，消费 Core 返回的 canonical replacement 与 alias replacement，确保 activity 合并、移动或改名后，历史 TXT 仍能被识别；候选验证失败时不提交部分 TOML、TXT 或数据库改动。
* 重构 pipeline 日期校验参数解析，移除对 CLI 配置中 `default_date_check_mode`、`convert_date_check_mode`、`ingest_date_check_mode` 和 `validate_logic_date_check_mode` 的依赖；日期校验策略不再由共享运行时配置下发，改由 CLI 命令参数明确控制，避免不同 pipeline 读取不同默认值。
* 更新 Windows CLI runtime 配置快照、报表模板和用户 activity hierarchy，使 CLI 使用与仓库 `config/program/**`、`config/user/**` 一致的配置和报表字段，避免运行时资源过期或缺失。
* 更新交换导出、TXT runtime client、查询命令和测试套件，使 CLI 能按 Core 的 `end_only`、canonical 配置和共享运行时协议处理记录、迁移与查询，确保导入、查询和 activity 迁移结果与 Core 保持一致。

### 修复 (Fixed)
* 修复 canonical leaf 合并和 alias token 改名时只更新 TOML、未同步历史 TXT 内容的问题，使旧 canonical 和 alias token 都能迁移到新的 activity。
* 修复日期校验模式从运行时配置读取导致命令行为不透明或不同 pipeline 默认值不一致的问题，改为由当前命令的显式参数决定。
