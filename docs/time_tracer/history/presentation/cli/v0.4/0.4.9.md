## [v0.4.9] - 2026-08-07

### 关联版本

* Core：`tracer_core v0.11.3`

### 技术改进/重构 (Changed/Refactor)

* 将 exchange 输入和输出文件契约从方向不明确的 `.tracer` 切换为加密 `.zip`，使非 TOML/TXT 导出内容更容易被用户识别并使用通用解压工具处理；同步更新命令行校验、默认输出测试和进度展示测试，旧 `.tracer` 不再作为当前输入格式。
* 清理 Windows CLI 对独立 unpack ABI 的依赖，使导入、导出和检查继续通过现有 exchange client 访问 Core 的 ZIP/AES 交换包能力。

### 弃用/删除 (Deprecated/Removed)

* 删除 `exchange unpack` 子命令及其 `ExchangeUnpackArgs`、handler、测试、CLI 公共导出和 `tracer_core_runtime_crypto_unpack_json` 符号调用；当前 CLI 通过 exchange 的导入、导出和检查流程处理加密 ZIP，不再提供独立解包 ABI。
