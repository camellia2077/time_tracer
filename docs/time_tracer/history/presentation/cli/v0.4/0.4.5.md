## [v0.4.5] - 2026-07-29

### 关联版本

* Core：`tracer_core v0.10.8`

### 技术改进/重构 (Changed/Refactor)

本次改动的目的是让 Windows CLI 的 activity 配置操作复用 `tracer_core v0.10.8` 的统一 hierarchy 语义。用户可以通过 CLI 修正 activity 的错误分组、将 activity 移动到其他 TOML 分类，或修改 canonical/`parent` 名称，并使后续统计报告按新的分组展示；CLI 负责命令行参数、文件迁移和事务编排，具体 hierarchy 语义由 Core 统一决定。

* 将 CLI runtime 配置目录从 `aliases/` 重命名为 `activity_hierarchy/`，同步更新 `config.toml`、bundle、同步状态、运行时快照和外部配置校验。
* CLI 改为复用 Core 返回的 activity hierarchy TOML 更新结果和 canonical replacement，支持 activity 在不同 `activity_hierarchy` TOML 分类之间迁移以及 canonical activity name 重命名。
* 更新 CLI runtime client、命令处理和迁移编排，使 activity hierarchy TOML 文件重命名及对应 `parent` 重命名复用 Core 语义，并在候选配置、TXT replacement、数据库重建和回滚完成后原子提交。
* 更新 CLI 的配置发现、诊断、exchange 和测试 suite，统一使用 `activity_hierarchy/` 路径，避免 Windows CLI 保留独立的 hierarchy 规则。

### 弃用/删除 (Deprecated/Removed)

* 删除 CLI 对旧 `aliases/` 目录和旧 alias hierarchy runtime client 的依赖；CLI 不再自行解析或推导 activity hierarchy canonical 迁移语义。

### 兼容性说明

* 外部 CLI 配置必须迁移到 `activity_hierarchy/`；旧 `aliases/` 路径不再作为运行时配置来源。
