## [v0.4.0] - 2026-06-18

### 新增功能 (Added)
* 新增 `query data` 命令行参数 `--missing-wake-anchor`，允许在 CLI 查询数据时显式指定是否过滤或包含缺失 wake 状态锚点的数据片段。

### 技术改进/重构 (Changed/Refactor)
* 升级 Rust CLI 与 C ABI 绑定模块，正确映射并将 `--missing-wake-anchor` 状态标志透传给上游 C++ 逻辑核心层。
* 适配 CLI 黑盒测试套件，在 `commands_query_data.toml` 中新增包含该可选参数的黑盒回归场景与退出码校验。
