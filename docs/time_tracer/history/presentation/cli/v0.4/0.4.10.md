## [v0.4.10] - 2026-08-11

### 关联版本

* Core：`v0.12.2`

### 技术改进/重构 (Changed/Refactor)
* 将 Windows CLI 从 `v0.4.9` 升级至 `v0.4.10`。
* 将查询评分枚举从 `SuggestScoreMode` 统一重命名为 `FrequentScoreMode`，保留 `--score-mode frequency|duration` 的使用方式。
* 将高频活动查询 action 从 `activity-suggest` 统一改为 `activity-frequent`，并同步更新请求构造与回归测试。

### 弃用/删除 (Deprecated/Removed)
* 删除 `SuggestScoreMode` 与 `activity-suggest` 的旧命名；调用方必须使用 `FrequentScoreMode` 和 `activity-frequent`。
