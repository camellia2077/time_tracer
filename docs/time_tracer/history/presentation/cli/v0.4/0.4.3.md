## [v0.4.3] - 2026-07-24

### 新增功能 (Added)
* 新增 `alias` 命令族，支持通过 `alias add`、`alias promote`、`alias move`、`alias rename-group-alias` 和 `alias add-group-alias` 修改 alias TOML 的层级与记录名称。
* 新增 alias TOML 的解析、校验和序列化，支持根级 `[aliases]` 与嵌套 group 共存；即使所有 alias 都已提升为 group，也保留显式的 `[aliases]` 父表，方便开发者识别根级 alias 的可用位置。
* 新增 `alias move` 的迁移流程，通过 `--input` 指定 TXT 根目录；仅当 canonical 实际发生变化时，才通过 Core runtime gateway 替换 TXT 中的旧 canonical、生成候选数据库并重建数据库，迁移失败时回滚 TOML、TXT 和数据库文件。

### 技术改进/重构 (Changed/Refactor)
* 重构 CLI runtime 的 TXT 客户端，复用 Core 的 canonical 活动名称批量替换接口，避免在 CLI 侧重复实现 canonical 文本处理。
* 更新 CLI 报告配置，为 Markdown、LaTeX 和 Typst 报告补充活动数量标签，并同步多语言 Markdown 配置目录。
* 升级 Windows Rust CLI 版本至 `0.4.3`，同步更新 Cargo 锁定信息和 runtime 配置 bundle 元数据。

### 修复 (Fixed)
* 修复 alias 层级迁移过程中 TOML、TXT 与数据库状态可能不一致的问题，增加候选文件和回滚处理。
