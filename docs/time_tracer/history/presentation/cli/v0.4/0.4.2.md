## [v0.4.2] - 2026-07-23

### 技术改进/重构 (Changed/Refactor)
* 升级 Windows Rust CLI 版本至 `0.4.2`，同步更新运行时配置 bundle 和配置快照校验信息。
* 重构 CLI runtime 配置入口，将 converter 主配置迁移为 `aliases/_system.toml`，并同步调整 alias 文件清单与配置路径元数据；alias 统一放在固定 `aliases/` 目录，移除旧的自定义 includes 路径索引，使 CLI 与 Core、Android 及 Log Generator 使用同一套配置布局。
* 更新 `doctor` 命令的运行环境检查，将旧的 `alias_mapping.toml` 文件检查改为 alias 配置目录检查，适配 Core 定义的固定 `aliases/` 配置布局。

### 弃用/删除 (Deprecated/Removed)
* 删除 CLI runtime 配置中对 `converter/interval_processor_config.toml`、`converter/alias_mapping.toml`、旧 `converter/aliases/` 路径及自定义 includes 索引的引用，统一使用固定 `aliases/` 目录下的配置文件。
