## [v0.4.1] - 2026-07-16

### 技术改进/重构 (Changed/Refactor)
* 重构项目树查询调用，移除对独立 `tracer_core_runtime_tree_json` 符号的依赖，改为通过统一 `runtime_query` action 请求包含节点持续时间、相对父节点占比和子节点的多层级 tree 响应。
* 更新 report composition 图表模板，使 pie chart 直接从新的完整 `tree` 响应生成当前层级数据，并保留子节点信息供多层级数据消费；同步调整黑盒测试断言。
* 同步 runtime 配置 bundle，移除 Core 已不再使用的 `duration_rules.toml` 及其相关配置校验入口；持续时间筛选不再在记录时把原始数据写死为不同 alias，而是保留原始记录、解析后写入数据库，并在查询阶段完成筛选。
* 更新 exchange 配置刷新 fixture，改用最小化的独立 TXT 输入验证 alias 配置导入后的查询链路，减少测试对完整 canonical 数据文件的耦合。

### 弃用/删除 (Deprecated/Removed)
* 删除 Rust CLI 对旧 tree ABI 加载、调用和响应模型的依赖，统一使用 runtime query 的多层级树查询入口。
