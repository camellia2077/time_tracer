## [v0.4.8] - 2026-08-04

### 技术改进/重构 (Changed/Refactor)
* 更新 `apps/cli/windows/rust/Cargo.toml` 中的 CLI 版本号，从 `0.4.7` 调整为 `0.4.8`。
* 重构 `apps/cli/windows/rust/src/core/runtime/invoke.rs`，按 capability 拆分 ABI 调用、响应 DTO、传输和错误映射，并保留原有 facade 与单一 ABI 边界。
* 拆分 `apps/cli/windows/rust/src/commands/handlers/alias.rs`，将层级树处理与跨文件迁移分别归入 `alias_tree.rs` 和 `alias_migration.rs`。
* 整理 `apps/cli/windows/rust/src/commands/handlers/report/`，分离请求构造、日期处理、格式处理和结果展示；保留 `report/mod.rs` 作为 session/dispatch facade，并将测试移至 `report/tests.rs`。
* 保留 `apps/cli/windows/rust/src/commands/handlers/exchange/mod.rs` 的 session、密码提示、进度和 dispatch facade，将测试移至 `exchange/tests.rs`。
* 拆分 `apps/cli/windows/rust/src/commands/handlers/txt.rs`，分别归置查看、追加、文本格式规则和测试职责。
* 整理 `apps/cli/windows/rust/src/cli/`，将根解析模型移至 `root.rs`、解析测试移至 `tests.rs`，保留原有公开类型重导出。
* 保持 CLI 命令名、参数、帮助文本、Runtime 请求契约和输出行为不变，并补充 Windows CLI 重构边界文档。
