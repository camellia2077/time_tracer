## [v0.12.9] - 2026-09-10

### 关联版本

* Android `v0.7.12`

### 新增功能 (Added)

* 将起床相关活动统一纳入 `behavior.toml` 顶层 `[canonical]`，递归生成其 canonical/alias 映射和内部 wake alias 集合，使活动转换与 TXT 起床语义共享同一配置来源。

### 技术改进/重构 (Changed/Refactor)

* 重构 `converter_config_loader`，抽取共享的 canonical 配置遍历与校验逻辑，统一 `.cpp` 和 `.module.cpp` 两条构建路径，避免配置解析实现漂移；普通睡眠活动继续由 `activity_hierarchy/sleep.toml` 管理。
* 调整行为配置校验，要求提供非空 `parent`、顶层 `[canonical]` 和 `sleep_inference.sleep_project_path`，将 wake alias、canonical 活动映射和睡眠推断配置收敛到明确的行为配置边界。
* 让 wake alias 与普通活动 alias 一样参与 alias → canonical 与 canonical → alias 双向名称转换，不再因具有 wake 语义而被活动名转换器特殊跳过。
* 将 wake 语义限定为点事件：只有名称匹配 wake alias 的点事件才建立起床时间；同名 interval 活动仍按普通活动处理，配置名称映射与时间语义判断保持分离。

### 修复 (Fixed)

* 修复 interval 活动被误判为 wake 的问题；只有名称匹配 wake alias 且以点事件形式出现时，才参与起床语义判断，普通睡眠 alias 不会被错误识别为 wake。
* 修复“上一活动”选择错误的问题：跨午夜活动可能因自然时间戳较大而被误认为逻辑日内最后记录，导致 Android `Use ... as start time` 使用错误的结束时间。现在 SQLite 查询、内存 tail 查找和月份替换流程统一按最新逻辑日、再按 `logical_id DESC` 选择上一条活动；`end_timestamp` 仅用于活动自身的时间计算。

### 弃用/删除 (Deprecated/Removed)

* 删除 `sleep_inference.wake_keywords` 的独立配置来源；wake alias 改由 `behavior.toml` 顶层 `[canonical]` 中的 alias 自动生成。
