## [v0.12.4] - 2026-08-13

### 关联版本

* Android `v0.7.4`

### 新增功能 (Added)
* 为范围型 Insights 的 `RangeInsightsData` 新增按日期分组的 `activity_days` 明细，向结构化消费端提供每一天的记录、时长与项目路径。
* 在 `CopyRangeFields` 中转发 `activity_days`，确保月、周、年及日期范围的包装结果保留活动明细。

### 技术改进/重构 (Changed/Refactor)
* 新增 `infra/insights/data/utils/activity_record_mapper.hpp`，统一 SQLite 活动记录到 `TimeRecord` 的字段映射、项目路径拼接及 `end_only` 类型解析。
* 让 Day、批量 Day、Month 与 Range Insights 查询复用活动记录映射器，消除重复实现并统一空文本字段的处理。

### 修复 (Fixed)
* 改用 `has_records` 判断 Range Insights 是否加载活动明细，使零时长的 `end_only` 记录仍能出现在范围查询结果中。
* 增加 Range Insights 对零时长 `end_only` 记录的 smoke 回归覆盖。
