## [v0.12.7] - 2026-08-17

### 新增功能 (Added)
* 新增 `ActivityAggregate` 共享活动聚合模型及对应模块导出，统一 Insights 日视图、区间视图及查询统计中的活动时长、活动次数和单次平均时长。
* 扩展 `insights-chart` 与 `insights-composition` 查询结果，提供活动次数、单次平均时长、众数、中位数、最小值/最大值、四分位数、变异系数、平均绝对偏差和平均分母天数等统计字段。
* 为 `insights-chart` 增加完整的 `root_tree` 层级数据，支持查询结果中的活动根节点与子节点选择。

### 技术改进/重构 (Changed/Refactor)
* 将旧的 `total_duration`、`activity_count` 和 `matched_record_count` 标量字段迁移为 `ActivityAggregate`，同步更新日/区间查询、批量聚合、结构化窗口元数据、导出和 Markdown/LaTeX/Typst formatter。
* 支持按活动日或自然日计算 Insights 平均值，并通过 `average_day_basis` 和 `average_denominator_days` 明确统计口径；活动日时长分布据此计算众数、中位数、四分位数等分布指标。
* 将 Insights 活动次数格式化参数扩展为 `int64`，避免较大统计值在 formatter 边界截断。
* 拆分查询服务中的 Insights chart、composition 内容构建逻辑，抽取日期窗口、筛选条件、树形 payload 和平均值计算等共享辅助代码。
* 规范化 `insights-chart` 根节点筛选输入，去除首尾空白，并在无记录窗口中保留完整层级树供选择。
* 将 daily Insights formatter 的内部命名从 `day_*` 统一为 `daily_*`，同步重命名 formatter、配置、工具和构建源路径。
* 重构 Android 静态 formatter 注册策略：禁用格式时注销既有 creator，重新启用时可恢复注册，不再注册抛出异常的占位 creator。
* 补充查询统计、空数据、平均值口径、分布统计、活动聚合和 formatter 策略切换的回归覆盖。

### 修复 (Fixed)
* 修复向已有日记录块写入事件时可能插入到末尾空白分隔行之后的问题，确保新事件保留在对应日块内。
