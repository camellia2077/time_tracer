## [v0.12.2] - 2026-08-11

### 关联版本

* CLI `v0.4.10`
* Android `v0.7.2`

### 技术改进/重构 (Changed/Refactor)
* 将活动高频查询从 `activity-suggest` 统一重命名为 `activity-frequent`，明确该能力基于最近记录的高频活动查询而非推荐，且名称不绑定频次或时长任一排序指标；同步更新 `DataQueryAction`、查询 DTO、repository、orchestrator、C++ module 导出及文本/语义 JSON 格式化器。
* 将高频活动查询的选项和结果模型统一为 `ActivityFrequentQueryOptions` 与 `ActivityFrequentRow`，语义 JSON action 同步改为 `activity_frequent`。
* 将默认查询窗口和数量统一复用 `kDefaultActivityFrequentLookbackDays` 与 `kDefaultActivityFrequentLimit`，删除 repository 与 orchestrator 中重复定义的默认值。

### 弃用/删除 (Deprecated/Removed)
* 删除 `ActivitySuggestion*`、`QueryActivitySuggestions`、`HandleActivitySuggestQuery`、`RenderActivitySuggestions*` 及 `activity-suggest` 的旧命名和兼容链路；调用方必须迁移到 `Frequent` 术语。
