## [v0.12.3] - 2026-08-12

### 关联版本
* Android `v0.7.3`

### 新增功能 (Added)
* 新增 `ResolveTxtDayEdit` 与 `ApplyTxtDayEdit`，为 Android 等消费层提供结构化 TXT 日编辑能力；Core 负责解析、校验和生成规范化 TXT，宿主负责编辑界面及所属月份 TXT 的持久化与同步。
* 新增 `TxtDayEditEvent` 及对应 request/response DTO，向宿主提供活动类型、标准化时间、备注和相邻活动时间边界。
* 为 runtime C ABI 新增 `resolve_day_edit` 和 `apply_day_edit` action，并在 `runtime_txt_day_block_json_contract_v1.md` 中定义请求、响应和回写规则。

### 技术改进/重构 (Changed/Refactor)
* 将混合点事件/区间事件的时间线检查提炼为 `AnalyzeMixedTimeline`，统一结构校验和结构化日编辑对跨午夜、重叠、无效区间及起床活动区间限制的判断。
* 让结构化日编辑通过既有 `TextParser` 解析候选 TXT，并在回写前执行 Core-owned timeline 校验；宿主时间选择器仅作为提前约束，不再成为规则来源。
* 在结构化日编辑的解析与回写中标准化点事件和区间事件时间，保留日备注及活动多行备注，并为跨午夜活动返回递增的时间线坐标。
* 扩展 pipeline workflow、API、workflow handler 与测试 fake 的转发链路，使 TXT 日编辑 DTO 从 Core 到 C ABI 保持一致。
