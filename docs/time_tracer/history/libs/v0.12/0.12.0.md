## [v0.12.0] - 2026-08-10

### 关联版本

* Android `v0.7.0`

### 技术改进/重构 (Changed/Refactor)
* 为配合 Android 将 Report Tab 迁移为 Insights（分析），将 `libs/tracer_core` 的报告领域从 `report/reporting` 统一重命名为 `insights`，覆盖领域模型、应用 API、配置加载、格式化与数据查询实现，并将运行时聚合入口由 `report()` 改为 `insights()`，避免 UI、配置、错误码与运行时接口出现两套术语。
* 将程序配置从 `[reports.*]` 与 `reports/**` 资源路径切换为 `[insights.*]` 与 `insights/**`，同步更新 Android bundle 配置路径、查询/导出流程和错误命名空间。
* 将 `libs/tracer_transport` 的 temporal 请求、响应、codec 和 capability 字段切换为 `Insights` 命名，包括 `TemporalInsightsRequestPayload`、`InsightsResponsePayload`、`runtime_temporal_insights_json` 与 `runtime_insights_batch_json`。
* 重构 CMake target、C++ module 与测试入口，将旧 reporting 依赖统一收敛到 insights 模块边界。

### 修复 (Fixed)
* 修复 core、transport 与运行时协议中同一分析能力同时使用 `report`、`reporting` 和 `insights` 三种命名造成的配置、错误码和能力协商不一致问题，统一使用 `insights.*` 错误码与协议字段。

### 弃用/删除 (Deprecated/Removed)
* 删除旧的 reporting API、DTO、port、formatter、query/export service、CMake target 和测试入口，包括 `IReportApi`、`Report*` payload、`runtime_codec_report` 及 `libs/tracer_core/src/infra/reporting/`。
* 删除对旧 `[reports.*]` 配置、`reports/**` 资源路径、`reporting.target.not_found` 错误码和旧 transport capability 字段的兼容；调用方必须迁移到 `insights` 命名。
