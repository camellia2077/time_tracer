## [v0.11.3] - 2026-08-07

### 关联版本

* 本版本的 `ActivityHierarchy` 配置编辑、加密 ZIP 交换包和 hierarchy leaf mapping 能力由 Android `v0.6.6` 和 Windows CLI `v0.4.9` 消费。

### 新增功能 (Added)

* 新增 `ActivityHierarchy` TOML 编辑契约，统一提供文档解析、校验、序列化、层级快照、跨文档移动以及 canonical/alias token 替换计划，避免 Android 与 CLI 各自维护 hierarchy 语义。
* 新增加密 ZIP 交换包编解码实现，将交换包从方向不明确的 `.tracer` 改为 `.zip`，方便用户识别并使用通用解压工具处理非 TOML/TXT 形式的导出内容。

### 技术改进/重构 (Changed/Refactor)

* 将 alias hierarchy 的 Core 类型、编辑入口、文本渲染依赖和查询动作统一迁移到 `ActivityHierarchy` / `kActivityHierarchyLeafMappings`，使 Core 成为配置解析、校验和 token migration 的唯一语义来源。
* 将交换包统一输出、导入和检查为加密 `.zip`：`.tracer` 只表达自定义容器而不能体现导出内容可解压的性质，因此不再作为当前交换包格式；进度改为交换包级别的阶段进度。
* 更新 `tracer_core` 的 CMake 源文件、模块导出、DTO、API 和测试，使 hierarchy 编辑、交换包 ZIP 契约及 alias/canonical 映射命名在 Core 内保持一致。

### 弃用/删除 (Deprecated/Removed)

* 删除旧 alias TOML editor/document 实现及其 `alias_toml_editor` 端口，改由 `activity_hierarchy_toml_editor` 承担统一语义。
* 删除 Core 内置通用 `FileCryptoService` 文件加密后端和独立交换包 unpack API；交换包仍保持加密，只通过 ZIP/AES package service 完成导入、导出和检查，旧 `.tracer` 格式不再支持。
