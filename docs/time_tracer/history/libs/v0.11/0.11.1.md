## [v0.11.1] - 2026-08-02

### 关联版本

* 本版本的结束时间记录、报表统计与 canonical 配置能力由 Android `v0.6.4` 和 Windows CLI `v0.4.7` 消费。

本版本聚焦于 Core 时间记录模型、报表统计与配置加载能力，补齐无法推导开始时间的记录表达，并统一查询与 Transport 的报表参数语义。

### 新增功能 (Added)
* 新增 `end_only` 时间记录类型：例如用户尚未记录任何活动时创建 point 记录，由于 point 的开始时间需要继承上一个活动的结束时间，该记录会保留为只有结束时间的活动事实；它不参与时长累计，但会计入活动出现次数。
* 新增报表组合统计模型，支持按活动树输出平均时长、平均次数和平均占比，并支持以活跃天数或自然日作为平均值分母。
* 新增配置驱动的每日状态定义，允许用户自定义要显示在格式化报告前部的活动层级及标签，替代此前硬编码的固定活动集合。
* 新增 canonical leaf merge 操作，将一个 canonical leaf 及其 aliases 合并到另一个 leaf，并生成 TOML 更新结果、canonical replacement 与 alias replacement，供 CLI 和 Android 复用完成 TXT 与数据库迁移。

### 技术改进/重构 (Changed/Refactor)
* 重构 SQLite 时间记录模式，在新建的 `time_records` 表中持久化 `record_kind`，用 `interval` 和 `end_only` 区分普通区间记录与只有结束时间的记录。
* 重构报表配置与格式化链路，将每日状态、结束时间格式和报表标签统一交由配置加载器提供；格式化报告前部改为展示用户配置的活动层级状态，不再固定依赖预设的唤醒锚点字段。
* 重构活动层级 TOML 编辑与迁移语义，将 `activity_hierarchy` TOML 中的根配置表从 `aliases` 统一更名为 `canonical`；`aliases` 只是 canonical 配置的一部分，且目录名已表达 activity hierarchy 语义，无需在 TOML 表名中重复，相关节点解析、移动、合并和重命名流程同步更新。
* 重构查询与报表统计接口，移除不再作为独立业务语义的 `missing_wake_anchor` 查询参数，改由配置驱动的每日状态表达相关信息；新增 `average_day_basis` 参数并同步更新 `tracer_transport` 编解码。
* 精简 `tracer_transport` 的 CLI 默认配置载荷，移除日期校验策略字段；日期校验策略不再由共享运行时配置下发，改由 CLI 命令参数明确控制。

### 修复 (Fixed)
* 修复结束时间记录在解析、校验、写入、查询和报表输出链路中的边界处理，避免将缺失的开始时间误当作普通区间或错误计入时长统计，同时保留其活动出现次数。
* 修复报表组合统计在空范围、无活跃日和自然日范围下的平均值计算，统一无有效分母时返回零。
