## [v0.11.2] - 2026-08-04

### 技术改进/重构 (Changed/Refactor)
* 重构 TXT 导入工作流，将导入执行、导入同步状态和工作流编排拆分到 `PipelineIngestService` 及专用 support 文件，降低 `PipelineWorkflow` 的职责与依赖复杂度。
* 重构持久化端口，将原合并的时间表仓储拆分为 `ITimeSheetWriteRepository` 与 `IIngestRuntimeRepository`，并补齐 SQLite 导入运行时仓储及对应模块导出。
* 重构报表用例实现，将查询、导出和公共报表转换逻辑拆分到独立 support 文件，保持 `report_api.cpp` 聚焦于用例入口与编排。
* 重构查询运行时的报表与内容映射，将原集中式映射实现拆分为 `query_runtime_service_mapping_content.cpp` 和 `query_runtime_service_report_content.cpp`，并同步调整 CMake 源文件清单。
* 重构 Android 静态报表格式化器注册，将格式化器构建器、范围报表适配和注册流程拆分，复用统一的范围报表 formatter 实现。
* 重构 `tracer_transport` Runtime Codec 公共面，将单体 `runtime_codec.hpp` 拆分为按 capabilities、workflow、query、report、export、ingest、tree 和 runtime 组织的头文件，并通过 `tracer.transport.runtime` 模块统一导出。
* 重构 `tracer_core` 的 C++ 模块与构建源文件组织，同步整理 application、persistence、query、reporting 和 transport 的模块依赖及 smoke test 覆盖。
* 整理 `tracer_adapters_io` 的文件读取与 processed JSON 校验边界，统一适配器实现与模块 smoke test 的接口使用。
