## [v0.11.0] - 2026-07-30

### 关联版本

- 本版本的配置分层、activity hierarchy 与统一交换内容能力由 Windows CLI `v0.4.6` 和 Android `v0.6.3` 消费。

本次改动的核心目的是重新划分导出内容的边界。旧版导出会包含部分程序 Runtime 依赖的资源，例如图表 HEX 颜色定义和 Markdown 字段文本；这些资源在 Android 中属于 APK 内置的 `assets`，本身不可修改，因此再次导入也不会产生实际效果。新版只导出用户真正需要备份和迁移的 `txt/**` 与 `config/user/**` TOML，使导入内容能够被解析并写入数据库，真正实现用户数据的导出与导入。CLI 和 Android 只负责输出，交换内容的构建和编码由 Core 统一完成。

### 新增功能 (Added)
* 新增 Core 统一交换内容 API，将 TXT 数据与 `config/user/**` 下可解析的用户 TOML 组织为统一内容，并支持后续编码结果交给 CLI 或 Android 输出。
* 新增 Core 统一交换内容 API，让 Core 负责交换数据的组织、解析和编码，避免 Windows CLI 与 Android 各自维护一套交换数据逻辑；两个客户端只负责调用 Core 并输出结果。
* 新增 Android 饼图调色板 TOML，并将可编辑的图表配置提取到 `config/user/`，使图表颜色与其他用户配置可以独立维护。

### 技术改进/重构 (Changed/Refactor)
* 重构根目录配置资源布局，将旧 `assets/` 配置分发结构迁移到 `config/`，并按 `program/`、`user/` 重新组织程序资源、用户配置、默认种子与运行时快照。
* 重构配置加载、校验、初始化、快照、清理及 Android/CLI 路径解析，明确 TXT 导入校验只依赖 `config/user/`，不再隐式加载 `config/program/`。
* 重构交换内容范围，改为只导出 `txt/**` 和 `config/user/**` 下可以解析、入库的 TOML；图表 HEX 颜色、Markdown/Typst 文本资源等程序运行资源不再导出或导入。
* 重构交换导出链路为 Core 构建内容、Core 编码，再由 CLI 或 Android 负责输出；将导出内容与压缩/加密及目标路径解耦，两个客户端复用同一 Core 交换实现。
* 重构交换包清单与 inspect/import 处理，统一记录 `config` 与 TXT payload 条目，并保持用户配置路径在 `config/user/**` 下可恢复。
* 重构 Android 配置编辑、图表加载和导入导出状态管理，移除旧的 alias 移动迁移服务，改由统一的 Core 配置迁移语义处理。

### 修复 (Fixed)
* 修复导入或验证候选 TXT 时依赖完整应用资源的问题，避免缺少报表、图表或 Markdown TOML 导致数据解析、入库和查询流程失败。
* 修复 CLI 与 Android 各自实现交换打包和输出保护造成的路径、配置范围不一致问题，统一使用 Core 生成的交换内容与清单。
