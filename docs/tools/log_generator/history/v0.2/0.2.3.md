## [v0.2.3] - 2026-07-23

### 新增功能 (Added)
* 新增活动备注的随机多行生成能力，根据 `max_lines` 在 1 至指定行数之间生成内容，并使用每行 `//` 前缀的物理续行格式输出；通过约 50% 的生成概率平均模拟有备注和无备注的活动记录。
* 新增日志生成器对新的 `config/aliases/` alias 配置目录的加载支持，直接读取目录中的 alias TOML 文件构建活动映射。
* 更新生成测试数据和单元测试，使日备注从旧的 `r` 前缀迁移为 `//` 前缀，并使多行活动备注从单行 `//` 内容中的换行表示迁移为每个物理续行都带有 `//`，与 Core 解析及 Android/CLI 消费端保持一致。

### 技术改进/重构 (Changed/Refactor)
* 重构活动备注生成配置，移除活动备注的独立 `generation_chance` 配置，统一使用便于实现且能平均覆盖有备注/无备注场景的固定 50% 判定，并通过 `max_lines` 随机生成 1 至 N 行，模拟用户备注长短不同的真实 TXT 数据并覆盖 Core 多行备注解析。
* 重构日备注和活动备注的 TXT 输出格式：日备注从 `r` 前缀迁移为 `//` 前缀；活动备注从在 `//` 内容中使用 `\n` 换行迁移为每个物理续行使用 `//` 前缀，确保生成结果符合 Core 的新解析规则，并可被 Android/CLI 按同一语义消费。
* 更新生成器帮助文本、配置加载错误信息和配置示例，使其与固定的 `config/aliases/*.toml` 目录布局及 Core 的 TXT 备注语法保持一致。

### 弃用/删除 (Deprecated/Removed)
* 删除对 `config/converter/alias_mapping.toml` 单文件入口及自定义 includes 路径的依赖，改用与 Core、Android 和 CLI 一致的固定 `config/aliases/` 目录作为 alias 配置来源。
