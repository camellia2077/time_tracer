## [v0.2.4] - 2026-07-24

### 新增功能 (Added)
* 新增 `--sleep-interval` 选项；仅在启用该选项且当天不是无睡眠日时，约有一半的有睡眠日会生成显式跨午夜 `sleep_day` interval，并让下一天的起点接续该 interval 的结束时间，避免重复生成重叠睡眠。
* 新增 HHMMSS 秒级时间输出，为 point 和 interval 事件保存并格式化日内秒数；秒数采用随机生成，不再全部固定为 `00`。

### 技术改进/重构 (Changed/Refactor)
* 重构活动起点生成算法，将一天的活动起点尽量均匀分配到上午、中午、下午和晚上四个时间段，并对生成结果排序，保证 point、interval 和 mixed 模式下同一天相邻活动起点严格递增；该约束针对活动起点，不代表活动持续时间均匀。
* 重构事件格式化流程，兼容 HHMM 与 HHMMSS 两种输出格式，同时让跨午夜 interval 使用实际的起止秒数写入 TXT。
* 更新 Log Generator 单元测试，覆盖 16 活动生成、四时段起点分布、秒级随机性、起点递增约束以及显式睡眠 interval 行为。
