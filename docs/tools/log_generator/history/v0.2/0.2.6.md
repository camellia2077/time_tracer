## [v0.2.6] - 2026-07-29

### 关联版本

* Core：`tracer_core v0.10.8`

### 技术改进/重构 (Changed/Refactor)

* 将 log_generator 的 canonical alias activity names 配置目录从 `aliases/` 切换为 `activity_hierarchy/`。这些 TOML 文件主要描述 activity 的层级结构，alias 和 canonical 都只是层级中的 value；使用 `aliases/` 容易造成配置只用于 alias 的误解，也会让“移动到某个 aliases TOML”等交流表述产生歧义。相关变更同步更新 CMake 安装路径、配置加载和测试资产来源。
* 更新生成器对 activity hierarchy TOML 的消费，使其与 Core 的新目录和 canonical activity name 口径一致。

### 弃用/删除 (Deprecated/Removed)

* 删除对旧 `aliases/` 配置目录的构建和运行时依赖。
