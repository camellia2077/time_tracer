## [v0.2.2] - 2026-07-16

### 新增功能 (Added)
* 新增 `--time-format` 命令行选项，支持使用 `HHMM` 或 `HHMMSS` 格式生成测试事件时间，默认改为输出 `HHMMSS`。
* 对齐当前 Core 与 Android 的原始记录输入格式，将点事件和区间事件默认生成为 `HHMMSS` 测试文本，同时保留生成 `HHMM` 测试样本的选项。

### 技术改进/重构 (Changed/Refactor)
* 将时间格式作为生成配置从命令行解析层传递至 `DayGenerator` 和 `EventLineFormatter`，统一 point event 与 interval event 的输出路径，并使生成数据与下游原始 TXT 输入契约保持一致。
* 增加 `HHMMSS` 时间格式的单元测试，并更新帮助文本和版本信息；log generator 版本升级为 `0.2.2`。
